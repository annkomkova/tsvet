# Цветочный — заглушка главной страницы

Итоговый код воркшопа. Он собран из тех же кусков, что в шпаргалке (`cheatsheet.html`), в том же порядке.

## Структура

```
index.html
css/fonts.css   — локальные шрифты Unbounded и Manrope (OFL)
css/style.css   — стили по БЭМ, адаптив внутри каждого куска
js/main.js      — анимации и форма, без зависимостей
fonts/          — woff2 (кириллица + латиница)
```

## Formspree

Замените `YOUR_FORM_ID` в атрибуте `action` формы на ID своей формы с formspree.io.
